# Central original baseline

This tree contains one earliest preserved baseline for every real file owned by
the five merged tweak topics. Paths below `original/` match their router or
LuCI installation paths.

Files introduced by the project are represented by `.absent` records:

- `usr/sbin/simmanager-fast-switch.absent`
- `usr/sbin/simmanager-jio-ensure.absent`
- `usr/lib/lua/luci/view/simmanager/automation_history.htm.absent`

The former root indexes and current-snapshot metadata are preserved under
`metadata/`. Intermediate stage documentation, patches and source checksums
remain available through Git history.

The original tree is immutable evidence. Future changes update only the
relevant topic's cumulative `changed/`, patch, documentation and manifest.
